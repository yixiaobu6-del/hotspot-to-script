# 热点转脚本

追热点写脚本，半天憋不出来？
**热点事件一键转系列视频脚本。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 脚本不再"难写"

- **系列规划**：3-5集系列视频，5种风格选择
- **平台适配**：抖音/快手/B站/视频号时长优化
- **模板库**：12套脚本模板+100条金句
- **一键生成**：填参数→秒出完整脚本

## 怎么用

打开 `web_app.html` → 输入热点事件 → 生成系列脚本
